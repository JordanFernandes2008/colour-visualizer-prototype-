# prototype

A surface visualizer prototype: stones, tiles, wood, wallpapers, panels, paints, curtains, rugs and furniture rendered into real rooms in the browser (WebGL2).

Open `index.html` via any static server, or visit the GitHub Pages site.

Credits: room photos from Unsplash (Unsplash License); timber and plaster textures from Poly Haven (CC0); stone, rug and fabric textures are generated in code.
